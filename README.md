# くるくる ずけい

かたちを まわすと どう見えるかを あてる、年長向けの あそび（回転図形の練習）。
ページ1枚（index.html）で動き、通信も外部の部品も使わない。

## あそびかた

- レベルは3つ。やさしい（みぎに1かい・3まいから えらぶ）／ふつう（みぎ・ひだり・2かい・4まい）／むずかしい（3かいまで・「なんかい まわした？」も出る）
- 問題の形は3つ
  - 2×2の ますに 4つの絵。カードを まわしたとき、●の えは どう見える？（4つの向きから えらぶ）
  - かたちを まわした形は どれ？（ほかの向きと 鏡の形が まざる）
  - もとの形と まわした形を見て、なんかい まわした？
- せいかいすると はっぱが もらえ、24まいで いきものが 1ぴき うまれて ずかんに はいる
- 答えたあと、もとの形が 実際に まわって見える（紙を回して確かめる練習の かわり）
- 「おとなのひと」を ながおし＝なまえ・1まわりの問題数・おとの あり／なし・記録の消去

## 動く端末

2012年の iPad（iOS 10.3.3・Safari 10.1 相当）で動く書き方だけで書いてある。
新しい書き方・絵文字は使わない（`tools/check_es5.py`・`tools/check_chars.py` が止める）。

## つくりかた

- 直すのは `src/` の中だけ（`app.js`＝しくみ／`ui.js`＝画面／`template.html`＝入れもの）
- `python3 tools/build_app.py` が `index.html` と `offline.appcache` を組み立てる
- 直したら `src/app.js` の `APP_VERSION` と `version.txt` を同じ数字で +1 する
- `zsh tools/check_all.zsh` で検査（組み立て・古い書き方・字の在庫・アイコン・ブラウザでの自己点検）
- ホーム画面の絵は `python3 tools/make_icon.py` だけが作る
